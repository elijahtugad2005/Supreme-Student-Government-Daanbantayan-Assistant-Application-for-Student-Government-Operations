Design System Architecture: Color Tokenization & Typography Specs

The SSG Office Assistant App utilizes an enterprise-grade, CSS-variable-driven design system engineered for high visual ergonomics across varied ambient environments. The interface architecture defines three specialized color themes paired with a calibrated typographic scale that balances institutional identity with digital usability.

1. Simplified Theme Color Architecture

  • Theme 1 · Dark (Maroon Classic Editorial): Anchored in Cebu Technological University's institutional maroon heritage. Uses deep charcoal (#1A1A1A) and surface gray (#252525) to minimize eye fatigue during night operations. Accentuation is provided by burnt orange (#D94F1F) and warm ivory (#F5F5DC) text, preventing harsh high-contrast glare.
  • Theme 2 · Light (Government Office / Clean Paper): Engineered specifically for daytime administrative auditing and document printing. Avoids blinding `#FFFFFF` backgrounds by establishing a soft neutral gray paper canvas (#F4F5F7) with pure white surface cards. Text is rendered in deep navy ink (#17202A), while interactive calls-to-action utilize government royal blue (#2563EB).
  • Theme 3 · Corporate (Cobalt Modern Dark): Tailored for data analytics, Document AI classification, and developer monitoring. Operates on deep midnight blue (#060B18) and sub-navy containers (#0A1428) highlighted with electric cobalt (#3B82F6) and subtle cyan border shimmers.

2. Typographic Scale & Role Assignments

  • Editorial Headings (Playfair Display / Instrument Serif): Dedicated to high-level institutional branding, officer leadership statements, and executive banners.
  • Application UI Sans (Inter & Geist Sans): The workhorse of the interface. Governs all interactive components including navigation bars, data tables, modals, button controls, and status badges with optimal legibility.
  • Impact Condensed (Bebas Neue): Used selectively for high-visibility metrics, such as Admin Dashboard page titles, financial liquidation totals, and calendar date blocks.
  • System Monospace (Geist Mono): Reserved strictly for technical data integrity—formatting student UID hashes, MongoDB GridFS file IDs, JWT claim inspect logs, and ISO audit timestamps.
